Spesifikasi Redesain — Tropical View Ubud

Situs asli: restoran — tropicalviewrestaurant.com · sanctuary — monkeyforestubud.com

Tujuan: mengonversi tamu yang baru keluar dari Ubud Monkey Forest Sanctuary dalam jendela "panas & lapar" 2 menit.

KPI Utama: klik klaim WhatsApp + reservasi yang berasal dari corong (funnel) /after-monkey-forest (dilacak per penempatan QR).

Spesifikasi ini dibangun di atas proyek Nuxt yang sudah ada (i18n, checkout WhatsApp, harga ganda, SQLite/MikroORM) — bukan menggantinya.

Perutean kampanye (QR → penawaran)

Satu halaman, banyak pintu masuk. QR/flyer mengodekan:

/after-monkey-forest?utm_source=qr_ticket&utm_medium=qr&utm_campaign=sanctuary&offer=sanctuary-combo

Penempatan yang dilampirkan (masing-masing utm_source sendiri): qr_exit, qr_ticket, qr_guesthouse, qr_driver, qr_shop, guide_card, sticker_table. Server menentukan penawaran aktif untuk audience=monkey_forest_guest jika tidak ada parameter offer.

2.3 /menu (P0)

Header → navigasi kategori melekat → grid menu dengan tombol harga ganda (dine-in vs takeaway, dipandu geofence) → detail item/tambah-ke-keranjang → banner "Penawaran sanctuary berlaku" → CTA.

2.4 /promotions (P0)

Header → Combo sanctuary tampil paling depan → grid unggulan → semua promo dengan tab kategori dari DB (menghapus bug 5 tab yang saat ini di-hardcode) → tampilkan validUntil, sembunyikan yang kedaluwarsa, tampilkan hitung mundur/lencana → detail promo (syarat) → CTA.

2.5 /reserve (P1)

Formulir: jumlah orang, tanggal, waktu, nama, telefon, email, catatan → POST /api/reservations → simpan + kembalikan tautan konfirmasi wa.me → layar sukses dengan "Tambahkan ke kalender".

2.6 /visit (P1)

Peta, alamat, "Buka sekarang" langsung (dihitung dari jam operasional), rute, rute jalan kaki dari sanctuary, parkir, transportasi. (Juga memperbaiki ketidakcocokan koordinat 20 km saat ini — dispesifikasikan terpisah.)

2.7 Tata Letak / global (P0)

Navigasi header + pengalih bahasa + keranjang + CTA utama (Reserve; berganti menjadi "Klaim penawaran" saat masuk lewat kampanye). Footer: kontak, jam, peta, sosial, TripAdvisor. JSON-LD Restaurant + useSeoMeta per halaman + hreflang.

3. Model Data Promosi (DB)

Saat ini promotion adalah tabel kartu datar (category teks bebas, valid_until teks, tanpa audience/waktu/bundle/penukaran). Redesain menjadi model yang mendukung kampanye. Pertahankan konvensi proyek: defineEntity, tabel snake_case, migrasi MikroORM append-only, seed sebagai sumber kebenaran.

3.2 promotion_category (baru — menggantikan category teks bebas)

id, slug, label, sort_order. Pola yang sama seperti Category; memberi data ke /api/promotion-categories (memperbaiki tab yang di-hardcode).

3.3 promotion_item (baru — bundle/combo)

id, promotion_id FK, menu_item_id FK null, custom_name null, quantity, role dengan role ∈ {included, choice, free, discount_target}.
→ "Sanctuary Cool-Down Combo" = 1 hidangan utama choice (dari sekumpulan) + 1 item free (es teh).

3.4 promotion_code (baru — penempatan QR / voucher)

id, promotion_id FK, code unik, channel, max_uses, used_count, starts_at, expires_at, is_active.
Satu kode per penempatan QR memungkinkan pelacakan per sumber dan pencegahan penyalahgunaan.

3.5 promotion_redemption (baru — analitik)

id, promotion_id FK null, code_id FK null, order_id FK null, reservation_id FK null, channel, utm_source, utm_medium, utm_campaign, redeemed_at.
Menghasilkan "N tamu minggu ini", A/B penawaran, dan ROI per kanal.

3.6 campaign (baru — opsional, registri penempatan)

id, slug, name, channel, utm_source, utm_medium, utm_campaign, landing_path, default_promotion_id FK null, qr_image_path, scan_count.
Memetakan penempatan fisik → URL pendaratan + penawaran default. Jika dilewati, enkodekan ini di promotion_code.channel.

3.7 promotion_translation (baru — i18n konten)

id, promotion_id FK, locale, title, subtitle, description, terms. Menjaga salinan promo di luar JSON i18n UI dan dapat diterjemahkan per bahasa. Unik (promotion_id, locale).

Relasi

promotion 1─* promotion_item, promotion 1─* promotion_code, promotion 1─* promotion_redemption, promotion 1─* promotion_translation, promotion_redemption *─1 order/reservation, promotion_item *─1 menu_item.

4. Lintas-Sektor

  • Analitik: kirim event untuk qr_scan, offer_view, menu_view, wa_claim_click, reserve_submit. Klik WhatsApp = konversi utama.
  • SEO: useSeoMeta per halaman, i18n.baseUrl + useLocaleHead() untuk hreflang, JSON-LD Restaurant + Offer, sitemap.xml yang dihasilkan, robots.txt, dan Google Business Profile yang dioptimalkan penuh (kategori, jam, tautan menu, penawaran, foto, Q&A).
  • Aksesibilitas: modal role="dialog" + focus trap + Escape; pertahankan target sentuh 44–48px.
  • Performa: host sendiri semua gambar (tanpa hotlink tropicalviewrestaurant.com/unsplash), WebP, lazy untuk bagian bawah, targetkan paint cepat pada wifi sanctuary yang lemah.

5. Urutan Pengerjaan (bertahap)

  1. P0 kampanye: perbaiki koordinat → migrasi promotion/promotion_category + seed "Sanctuary Cool-Down Combo" → bangun ulang /after-monkey-forest (hero, penawaran, bukti sosial, peta, bilah melekat) → saluran QR + UTM → GBP.
  2. P0 konten: /promotions tab dari DB + kedaluwarsa + unggulan lebih dulu; banner penawaran /menu; beranda niat ganda.
  3. P1: /reserve (formulir → DB + WhatsApp), /visit dengan "Buka sekarang"; pelacakan penukaran + analitik.
  4. P2/P3: /about, /contact, legal, bahasa tambahan, promotion_translation.

Nuxt-Resto-Website — Code Audit Report

Audited: 2026-09-30 • Updated: 2026-10-13 (post SQLite + MikroORM migration) • Framework: Nuxt 4 + Vue 3 + TypeScript

Overview

Audit of the Tropical View Ubud restaurant website. The project implements a marketing site with dual pricing (takeaway vs dine-in via geofence), WhatsApp checkout, and EN/ID i18n.

Update 2026-10-13: the JSON-file data store was replaced with SQLite + MikroORM v7 (decorator-free defineEntity). This closed 3 audit issues and added new data-layer capabilities (contact persistence, reservations, orders). The remaining issues below are unaffected by that work.

Changelog — 2026-10-13

Data layer migrated: JSON files → SQLite (MikroORM v7) 8 entities via defineEntity (no decorators), Nitro plugin with per-request em.fork(), migration + seed, DB-backed API routes.
  • Resolved: contact form now persists (#1); production readFileSync break removed (#2); WhatsApp number unified to the DB value (#3).
  • Added: contact_message, reservation, order / order_item tables + POST/GET endpoints.
  • Frontend rewired: menu category is now an object; restaurant is flat; all hardcoded WhatsApp links + map embed read from the DB.
  • Removed: @mikro-orm/decorators, reflect-metadata, experimentalDecorators config, dedicated CLI tsconfig.
